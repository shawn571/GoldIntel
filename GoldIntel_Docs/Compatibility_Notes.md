## 4. Differences from the Classic-era assumptions

See Phase1_PostValidation_Review.md section 2 (24 rows). Short list: interface number; modern API instead of Classic names; Lua 5.1 confirmed; realm names exist in the beta; project ID 18; legacy professions, auction and trade-skill APIs absent; events can be restricted; secret values exist.

## 5. Rules that follow from the evidence

- Only `Platform/Events.lua` calls `RegisterEvent`; restricted events are never registered; names are checked with `C_EventUtils.IsEventValid` (D-025).
- Never gate behavior on `WOW_PROJECT_ID`.
- Never parse chat or combat events to obtain money; use the live balance.
- Every client-supplied value is checked with `IsSecret` before comparison or arithmetic.
- Code uses 5.1 only: no `load`, `table.unpack`, `//`, `goto`, long brackets (D-024).
- Key characters by GUID only; realm text is at most an attribute.
- Treat a capability as unknown (not ok) when it cannot be checked safely.

- Profession rank semantics of `GetProfessionInfo` in Forever.
- Behavior of the auction house, mail, trade, loot and vendor APIs in Forever (not visited).

- Whether the TOC accepts a comma-separated Interface list (OI-10).

## User-reported item value facts (2026-10-19, NOT measured; verify in 3b-3 Session E / Phase 6)
- Some items have no vendor price (for example enchanting mats, quest items). Enchanting mats can be sold on the AH but not to a vendor. Quest items can never be sold: no vendor value, no AH value. Sell price 0 is a KNOWN value (`noVendor`), not unknown (consistent with E-30: Hearthstone 0).
- Soulbound items can have vendor prices but not AH prices. If armor or weapon and disenchantable, they can have a disenchant value, which some addons estimate from AH prices of the possible mats and each mat's drop chance. Such an estimate is Phase 6 "Current Market Value" (D-063), never a stored lot valuation; 3b-3 records disenchants only as consume + materials (D-071).
- A bind-on-equip item becomes soulbound after acquisition; the lot's `bound` flag (bind type 1 or 4 at acquisition) does not follow that. Phase 6 must read the current bound state.
